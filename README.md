## 🔭 En qué estoy trabajando ahora

**[AIENC](https://github.com/ErisGC/AIENCMASTER)** — Portal institucional con panel administrativo
multi-rol para la *Asociación de Iglesias Evangélicas del Norte de Colombia*. Monorepo
NestJS + Next.js + Flutter Android. Permisos granulares ROOT/ADMIN, sistema de
invitaciones con cadena de confianza, multi-iglesia, auditoría completa, distribución
APK firmado vía GitHub Releases.
